## 10/25流水灯作业实现思路
1.为什么不使用HAL_DELAY
  阻塞使程序被卡在原地，不能做别的事
2.使用推挽，LED 一端接 3.3V、另一端接引脚，引脚输出低电平时才有电流，灯亮；所以 RESET = 亮，SET = 灭
3.我需要让“当前时间”每过 500 毫秒就换下一盏灯，就需要知道下一次换灯的时间点和现在是第几盏灯
  那么先让所有的灯熄灭，点亮0号灯，设置下一次换灯时间为当前时间 + 500
  每循环一次，先读取当前时间再计算与500的差值，判断是否小于0，时间没到就直接返回，到了就换灯
4.如果直接使用delay等待500ms，主循环就无法进入下一圈

**注明：为了避免delay的影响，我设计了运行思路，具体的代码实现我借用了deepseekharness的指导**
